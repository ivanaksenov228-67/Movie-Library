# Movie Library (Личная кинотека)

**Автор:** Иван Аксенов

## Описание

GUI-приложение для хранения информации о фильмах. Позволяет добавлять, просматривать, фильтровать и удалять фильмы. Данные сохраняются в формате JSON.

## Функциональность

- Добавление фильмов с указанием названия, жанра, года выпуска и рейтинга
- Просмотр всех фильмов в таблице
- Фильтрация по жанру и году выпуска
- Удаление фильмов
- Сохранение и загрузка данных через JSON
- Валидация ввода (год - число, рейтинг 0-10)

## Установка и запуск

1. Убедитесь, что установлен Python 3.6+
2. Скачайте файл `main.py`
3. Запустите приложение:
   ```bash
   python main.py
